# SyncTogether — Play Console Release Notes

Paste the chosen text into **Production → Create new release → Release notes (en-US)**.
Google Play allows **up to 500 characters** for release notes.

## Recommended (short — 168 chars)

```
What's new:
• Watch YouTube Shorts together in sync.
• Swipe between Shorts or tap Previous/Next.
• Fixed rewarded ad progress not updating.
• Room owners can now delete their rooms.
• Bug fixes and stability improvements.
```

• YouTube Shorts Together in sync rooms.
